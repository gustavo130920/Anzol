# Telas para gravar — vídeo-pitch do Anzol

> Grave as telas **separadas da narração** e encaixe na edição. Cada tomada indica o trecho do roteiro (`docs/roteiro-video.md`).

## Preparação (uma vez, antes de tudo)

1. Use o site publicado: **https://gustavo130920.github.io/Anzol/** (ou o servidor local: `powershell -ExecutionPolicy Bypass -File tools\servidor.ps1`).
2. Navegador em **tela cheia**, janela 1920×1080, zoom do navegador em **125%** (texto legível no vídeo). Notificações do sistema **desligadas**.
3. Abra numa **janela anônima** (começa sem dados de testes anteriores). Tema **preto** (padrão).
4. Se não usar janela anônima: aba **Radar** → "Recomeçar o Radar deste aparelho"; aba **Testes** → "Recomeçar meu progresso".
5. Grave com o cursor visível e movimentos lentos. Respire 1 s antes e depois de cada clique.

## Slides de apoio (blocos sem demonstração)

Arquivo: `docs/slides/index.html` (15 slides, preto e rosa, cada número com fonte e data).

- **Abrir:** com o servidor local ligado, `http://localhost:8080/docs/slides/index.html` (ou dois cliques no arquivo).
- **Teclas:** → / espaço avançam · ← volta · **F** tela cheia · **N** mostra o número do slide e o trecho do roteiro (deixe escondido ao gravar).

## Cuidados

- Nada de dados pessoais reais na tela (use só os exemplos do app).
- Não mostrar a pasta do computador nem o editor de código, só o site, o diagrama e o GitHub Actions.
- Se algo der errado numa tomada, recomece a partir da preparação (janela anônima nova).
- Se a internet cair, o OCR do exemplo usa o texto pré-extraído (aparece "SIMULAÇÃO: texto pré-extraído"); a demonstração continua válida, mas prefira gravar com internet.
